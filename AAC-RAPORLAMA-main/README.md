# AAC Raporlama Eklentisi

**AAC Minecraft sunucuları için geliştirilmiş**
**oyuncuların istedikleri kişileri kolayca raporlayabilmesini sağlayan**
**async tabanlı bir raporlama eklentisidir**

**Bu eklenti ilk olarak kişisel kullanım amacıyla geliştirilmiş**
**daha sonra açık kaynak olarak paylaşılmasına karar verilmiştir**

-----------------------------------------------
🚀 Özellikler
- Async altyapı
- Hızlı oyuncu raporlama sistemi
- Yöneticiye anlık rapor bildirimleri
- Rapor izleme (watch) modu
- Config ve dil dosyası desteği
- Basit ve kullanıcı dostu kullanım
-----------------------------------------------

⌨ Oyuncu Komutları
- /raporla
- /raporla isim
- /raporlar
- /aacwatct

Yönetici Komutları
- /aacsystem alerts
- /aacsystem reload

🎯 Kimler İçin?

- Sunucusunda düzenli rapor sistemi isteyenler
- Hafif ve performanslı async eklenti arayanlar
- Yöneticiye anlık bildirim isteyen sunucu sahipleri
